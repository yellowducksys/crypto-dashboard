# 🪙 Crypto Price Tracker

A live cryptocurrency dashboard built with **React**, **Chart.js**, and the **CoinGecko API**. Track real-time prices, view historical charts, and manage your portfolio — all in the browser.

## 🔗 Live Demo

👉 [https://yellowducksys.github.io/crypto-dashboard](https://yellowducksys.github.io/crypto-dashboard)

## ✨ Features

- 📈 Live prices for top 30 cryptocurrencies (auto-refreshes every 60 seconds)
- 🔍 Search coins by name or symbol
- 📊 Interactive price history charts (24h, 7d, 30d, 90d)
- 💼 Portfolio value calculator with localStorage persistence
- 🏆 Top 24h gainer highlight

## 🛠️ Tech Stack

| Technology | Usage |
|---|---|
| React 18 (CDN) | UI components |
| Chart.js 4 | Price history charts |
| Bootstrap 5 | Responsive layout |
| CoinGecko API | Live crypto data |

## 📁 Project Structure

```
crypto-dashboard/
├── index.html   # Entry point
├── app.js       # React app logic
└── style.css    # Custom styles
```

## 🚀 Run Locally

Just open `index.html` in your browser — no build step needed!
